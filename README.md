Приложение на Python (Tkinter) для управления клиентами и их заказами.

## Основные возможности
- Поиск клиента по имени  
- Добавление нового клиента (имя, телефон, email)  
- Создание заказа для выбранного клиента  
- Добавление товаров в заказ (название, цена, количество)  
- Автоматический подсчёт общей суммы заказа
